# Contributing

Thank you for reading *Building with SAP Signavio* and for helping to improve it.

## Report an erratum

Open a [GitHub Issue](https://github.com/KrSujit/building_with_signavio/issues/new/choose) with the **Erratum** template. Please include:

- **Where:** chapter, section, and page (state whether print or e-book), or the file path in this repository.
- **What it says** and **what it should say**.
- **How you found it:** for example the SAP Signavio product and release you used, the file you imported, or the query you ran, with any error message.
- A screenshot if the issue is on a screen. Remove any customer or personal data first.

## Ask a question

Use the **Question** template. Questions about the book's method and companion files are welcome; questions about your own SAP Signavio contract, licensing or tenant are better directed to SAP support.

## Pull requests

Small fixes to companion files (a broken model, a wrong column, a typo in a README) are welcome as pull requests. Please describe the change and, for models, run the checks in [validation/README.md](validation/README.md) first. Do not add SAP template content or any real company or personal data.

Confirmed errata are listed in [CHANGELOG.md](CHANGELOG.md).
