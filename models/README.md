# Process models

Velora Group SE's order-to-cash models from the book, as BPMN 2.0 XML and DMN 1.3 XML. Every file imports into SAP Signavio Process Manager and into other BPMN 2.0 tools (for example bpmn.io or Camunda Modeler). All content is fictional.

In the book, the models are listed under the companion file names `S04_O2C_AsIs.bpmn` (Chapters 4 and 6), `S05_Credit_Block_Brno_AsIs.bpmn` (Chapter 5) and `S10_Model_Approval.bpmn` (Chapter 10). Here, each diagram is its own file, named after the diagram.

## Import into SAP Signavio Process Manager

1. Download the file (on GitHub: open the file, then **Download raw file**).
2. In Process Manager, open the **Explorer** and select the folder where the model should go.
3. Choose **Import / Export > Import BPMN 2.0 XML** (for the DMN file: the DMN import in the same menu), select the file, and confirm.
4. Open the model and run **Check syntax**.

Notes:

- Collapsed subprocesses in the L2 models and in *Manage credit* are empty on purpose. After import, link each one to its L3 model (Chapter 6).
- Import the L3 models before you link them, so that the targets exist.
- To use *Velora - Model approval (ISO)* as a workflow, import it in Process Governance with **Create > Import BPMN** (Chapter 10).
- Menu labels change between SAP Signavio releases. If your screen differs, look for the import function in the Explorer.
