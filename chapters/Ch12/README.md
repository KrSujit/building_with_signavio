# Chapter 12 – What the Data Says

Companion files for *Building with SAP Signavio*. Velora Group SE is a fictional company; all data is fictional.

| File | What it is | Used in the book |
|---|---|---|
| S13_O2C_EventLog.csv → [`data/S13_O2C_EventLog.zip`](../../data/S13_O2C_EventLog.zip) | Fictional O2C event log: 41,300 sales orders, 468,799 events; columns case_id, activity, timestamp, plant, user, system (zipped, 4.7 MB; 32.8 MB unzipped) | Section 12.5, Step 1; used throughout Part IV |
| S13_O2C_CaseAttributes.csv → [`data/S13_O2C_CaseAttributes.zip`](../../data/S13_O2C_CaseAttributes.zip) | Case attributes: customer, segment, sales organization, plant, order value, payment terms, order lines, drop shipment, created month (zipped) | Section 12.5, Step 1 |

Unzip both files before the upload. The case ID column is called `case_id` in both files (map it as the case ID). Both files are regenerated byte for byte by `data/gen_o2c.js`.
