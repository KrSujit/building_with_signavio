# Chapter 11 – Simulate Before You Hire

Companion files for *Building with SAP Signavio*. Velora Group SE is a fictional company; all data is fictional.

| File | What it is | Used in the book |
|---|---|---|
| S11_Simulation_Scenarios.xlsx | All simulation inputs for scenarios A to D (Costs, Duration, Frequency, Resources tabs), shared assumptions, probability checks, and the results of Figure 11.2 with space for your own run. Values not printed in the book are marked *Estimate* | Sections 11.2–11.3; build in Section 11.5, Steps 2–4 |
| S11_Report_Examples.xlsx | Example outputs of the RACI (Figure 11.5), responsibility handovers (Figure 11.6), IT system usage (first run and O2C counts), modeling conventions (Figure 11.9 and trend), and an illustrative static cost analysis calculated from the scenario A inputs | Section 11.4; build in Section 11.5, Step 5 |

Models used: `models/Release_credit_block_Brno_as_is.bpmn` (scenarios A and B). The proposal model *Release credit block – standard (proposal)* (scenarios C and D) is built in Chapter 8, Figure 8.3.
