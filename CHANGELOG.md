# Changelog

All notable changes to the companion files are recorded here. Versions follow [Semantic Versioning](https://semver.org/).

## [1.0.0] - unreleased

First release, matching the first edition of *Building with SAP Signavio*.

- Process models: ten BPMN 2.0 models and one DMN 1.3 decision, with PNG previews and generator scripts.
- Book tables as CSV, per chapter.
- SQL and SiGNAL queries for Chapters 13 to 16.
- Companion files per chapter and the fictional O2C event log.
- Release asset `velora-sap-ecc-dataset-v1.zip`: 51 fictional SAP ECC tables with generator and fingerprints.
- Validation scripts for the BPMN and DMN files.
