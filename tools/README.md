# Tools: model generators

The BPMN and DMN files in [`models/`](../models/) are generated by the scripts in this folder, not drawn by hand. The scripts make the models reproducible and keep their layout (BPMN diagram interchange) clean.

| File | What it does |
|---|---|
| `bpmn.py` | Small BPMN 2.0 XML writer with automatic grid layout (column = position in the flow, lane = row), and `lint()`, a layout check for flows that cross shapes or lie on other flows |
| `models.py` | The ten Velora models (one function per model) |
| `dmn.py` | The DMN 1.3 decision *Decide credit release* (`S08_Credit_Check.dmn`), including the DRD layout |
| `mk_bpmn.py` | Writes all models; optionally renders PNG previews |

## Regenerate the models

Needs Python 3.8 or later, standard library only.

```bash
python3 tools/mk_bpmn.py                 # writes models/*.bpmn and models/S08_Credit_Check.dmn
python3 tools/mk_bpmn.py --out /tmp/m    # writes to another folder
python3 tools/dmn.py /tmp/m              # the DMN file on its own
```

The output is deterministic. To confirm that the files in `models/` are the generator's output:

```bash
python3 tools/mk_bpmn.py --out /tmp/m && diff -r --exclude=previews --exclude=README.md models /tmp/m
```

## Render the previews (optional)

The PNG files in `models/previews/` are rendered with [bpmn-js](https://bpmn.io/toolkit/bpmn-js/) in a headless browser.

```bash
npm install bpmn-js
pip install playwright && playwright install chromium
python3 tools/mk_bpmn.py --png           # also writes models/previews/*.png
```

Use `--bpmn-js PATH` (or the `BPMN_JS` environment variable) if `bpmn-viewer.production.min.js` is not in `node_modules/bpmn-js/dist/` of the repository root.

## Validate

After a change, run the checks in [validation/README.md](../validation/README.md): XML schema, bpmn-moddle and dmn-moddle import, bpmnlint, and the DMN rule test. Then import the changed model into SAP Signavio Process Manager and run **Check syntax**.
